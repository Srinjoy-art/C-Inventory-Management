# Inventory Management System in C

This is a small project I built while learning C programming. I wanted to practise using structures, functions and file handling in a program that manages something practical.

The program is menu-driven and allows users to maintain basic inventory records through the terminal.

## Features

- Add new products to the inventory
- View all available products
- Search for a product
- Update product details
- Sell products and update stock quantities
- Check products with low stock
- Save and load inventory records using a file

## Built With

- C Programming Language
- Standard C Library
- File handling for storing inventory data

## How to Run

Make sure you have a C compiler such as GCC installed.

**1. Compile the program**

```bash
gcc Inventory_Management_System.c -o inventory
```

**2. Run on Windows**

```bash
.\inventory.exe
```

On Linux or macOS, run:

```bash
./inventory
```

Replace `Inventory_Management_System.c` with the actual name of your source file if it is different.

## Concepts Practised

- Structures (`struct`)
- Functions and arrays
- Loops and conditional statements
- Searching and updating records
- File handling using `fopen()`, `fscanf()` and `fprintf()`
- Menu-driven programming
